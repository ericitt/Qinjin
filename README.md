# 勤进科技 · MVP

一个真正的在线 Web 应用（不再是内嵌JSON的静态HTML快照），2-3人内部使用，无需登录。

**技术栈**：Next.js（Vercel部署）+ Supabase（托管Postgres）+ Claude API（AI询价助手）。全部免费额度，不需要自己的服务器。

## 核心功能

1. **智能查询**（`/`）— 实时搜数据库，型号/规格/品牌模糊搜索，详情页含成本/毛利/出货历史/BOM归属/供应商报价
2. **AI 询价助手**（`/bom`）— 粘贴客户发来的模糊BOM文本，Claude API 清洗提取型号，四档匹配数据库（精确/目录参考/模糊/未找到），人工确认后一键提交：已有型号记报价，全新型号自动建档
3. **出货明细**（`/orders`）— 按出货频次排序的历史记录
4. **供应商管理**（`/suppliers`）— 218个品牌的自动评分（出货频次+累计量+价格稳定性），9家认证供应商联系方式

## 已导入的真实数据

- 5327 个型号（1402个真实出货过 + 3925个目录参考价，另加105个BOM专属供应商料号）
- 5974 条完整出货记录（不是截断版）
- 142 条 BOM 明细（DHS100-0D75S2 驱动器）
- 218 个品牌统计 + 9 家认证供应商联系方式

## 快速开始

看 `DEPLOY.md`（Supabase+Vercel版），15分钟能部署起来，不需要域名、不需要服务器。

## 目录结构

```
app/              Next.js 页面 + API routes
lib/              数据库连接(适配Supabase连接池)、Claude API封装、匹配逻辑、评分算法
sql/init.sql      表结构
sql/seed.sql      真实历史数据（1.3MB，已清洗好，直接导入）
scripts/seed.js   一键导入脚本
```

## 跟之前版本的关系

- v5.html（静态离线单文件版）已废弃不再维护
- 业务逻辑（四档匹配、评分公式、毛利计算）从 v5.html 直接照搬，只是数据源从"内嵌JSON快照"换成了"实时查数据库"
- AI助手最初接的是DeepSeek API（为了国内访问速度），现已切换为Claude API
- 后端最初设计是自建服务器（阿里云ECS+Docker+自建Postgres），后改为Supabase+Vercel托管方案（免费、更简单）；如果以后还想换回自建服务器，代码逻辑不用大改，只是`lib/db.ts`的连接方式和部署步骤不同
